# Журнал изменений

Формат: дата, что поменяли, зачем, как проверили. Новое сверху.

## 2026-11-14: v0.2.0, баги, простой интерфейс, настоящее демо
Три параллельные ветки, слиты в main: `fix-bugs` (Sonnet), `ux-simplify` (Opus), `real-demo` (Sonnet).

Баги (все 8 из списка ниже исправлены, `src/services/importerExporter.ts`, если не указано иное):
- Импорт папки: сначала `steps.json`, затем любой `.json` с массивом `steps`.
- Плеер: «Тренажёр / Обзор» теперь реально разный (в обзоре рамка не кликается).
- Файл проекта для правок: `exportStandaloneHtml(..., { publicBlur: false, embedSource: true })` вкладывает
  `<script type="application/json" id="guide-source">` (исходники, блюр, маски, общий блюр, все поля шагов);
  `importFromStandaloneHtml` восстанавливает из него без потерь. В публичную версию блок не попадает.
- `global_blur` в `steps.json` читается и пишется.
- Захват стартует с `displaySurface: 'browser'` (вкладка, без адресной строки).
- Язык плеера: по умолчанию из `META.default_lang`, выбор хранится по ключу `lang:<title_en>`.
- Экранирование `<title>`, JSON в `<script>` (`<` → `<`), название раздела через textContent.
- Добавлен `LICENSE` (MIT). Клавиши F и стрелки не срабатывают в полях ввода.
- Найдено попутно: бесконечный цикл рендера в `InteractiveBoxEditor.tsx` (около 95 ошибок «Maximum update depth» за 3 с), исправлено.

Интерфейс (`App.tsx`, `WelcomeTourModal.tsx`, `uiTranslations.ts`):
- Тур из 3 шагов: Запишите, Подпишите, Скачайте; в конце «Создать гайд» / «Открыть демо».
- Редактор: справа «Шаг N из M», тип действия, подпись, диктовка, «Просмотреть и скачать», всё видно без прокрутки
  при 1440x900 и 1280x720. Блюр, маски, ИИ, масштаб, раздел, выбор скриншота свёрнуты в «Размытие и другие инструменты».
- Превью шагов без тегов, одна кнопка «Приватность и ИИ», демо открывается в редакторе, новый гайд на записи.
- Экспорт: «Гайд для студентов (.html)» и «Сохранить проект для редактирования (.html)», остальное под «Другие форматы».
  На главной одна кнопка «Открыть гайд или проект» и заметка, что гайды живут только в этом браузере.
- Убраны «Высокий холст» и полное скрытие списка шагов. Быстрые кнопки действий не затирают ручную подпись.

Демо (`src/db/database.ts`, `public/demo/fabric-demo.html`, 659 КБ): шаги 1–8 опубликованного гайда IMSALES
(workspace, тип Fabric, lakehouse), загружаются через `importFromStandaloneHtml`. Синтетические картинки удалены.

Проверено в браузере на собранном main: тур, демо в редакторе, проект для правок туда и обратно без потерь
(исходники байт в байт, блюр, маски, общий блюр, голос, `</script>` в тексте), публичная версия без исходников,
тренажёр/обзор и язык в скачанном гайде, 0 ошибок в консоли. Захват экрана и диктовка руками не проверялись.

Осталось (кандидаты на следующие шаги):
- Подпись редактируется как сырой HTML (`<b>`, `<i>`): нужна кнопка «Жирный» или визуальный редактор.
- Модалка «Приватность и ИИ» (около 1260 строк) перегружена, `LiveCaptureWorkspace.tsx` ещё с эмодзи и «—».
- Имя файла для студентов фиксированное `guide-public.html`, лучше по названию проекта.
- Раскрывать «Размытие и другие инструменты», если на кадре уже есть блюр.
- При нарезке урока файл проекта вкладывает весь проект; язык плеера общий у гайдов с одинаковым названием.
- Основной JS-бандл больше 500 КБ (предупреждение Vite).
