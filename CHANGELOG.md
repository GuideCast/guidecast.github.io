## 2026-11-14: v0.3.1, переключение вкладки, путь назад из тура, «Попробуйте сами»
Переключение на выбранную вкладку (`LiveCaptureWorkspace.tsx`):
- `getDisplayMedia` теперь получает `CaptureController`, сразу после ответа вызывается
  `setFocusBehavior('focus-captured-surface')` (из контекста приложения, как и сам вызов).
- Результат проверки честный: в Chrome 157 с настоящим окном выбора вкладки (я нажимал «Поделиться» вручную
  через эмуляцию мыши) окно Chrome осталось на вкладке редактора, переключения НЕ произошло. Подтвердить, что
  вызов вообще что-то меняет, не удалось: ни с контроллером, ни без него вкладка сама не открылась (проверял по
  заголовку окна Chrome). Возможная причина: фокус держит окно плавающего пульта.
- Поэтому добавлен запасной вариант: если через 1,5 с после «Поделиться» наша вкладка всё ещё на переднем плане,
  в плавающем пульте на 20 секунд появляется жёлтая плашка «Запись началась. Если Chrome не открыл вашу программу
  сам, нажмите на её вкладку. Пульт останется поверх.» Плашка исчезает, когда вкладка уходит в фон.
- Записано: пульт остаётся поверх, вкладку с программой преподаватель открывает одним щелчком.

Тур (`App.tsx`, `public/demo/how-to-guide.html`):
- Выбранный путь назад: тур открывается внутри приложения (iframe), а не в новой вкладке. Над ним зелёная кнопка
  «Назад на главную» и подсказка «Нажимайте на красную рамку». Закрывать вкладку браузера не нужно.
- Последний шаг (18): «Теперь попробуйте сами: откройте любой сайт в соседней вкладке (например, Википедию) и
  снимите 3 шага» и крупная зелёная кнопка «Now try it yourself» / «Попробовать самому». Кнопка ведёт на
  `../?new=1`: приложение создаёт новый гайд и открывает вкладку записи, параметр убирается из адреса, при
  перезагрузке второй гайд не создаётся. Окно приветствия при этом не показывается.
- Подпись шага 18 правилась прямо в файле демо (и в плеере, и во вложенном исходнике), экраны не пересобирались.

Проверено (видимый Chrome 157, Playwright): тур открывается внутри приложения, кнопка «Назад на главную» возвращает
на главную; 18 шагов проходятся кнопкой «Далее», на 18-м кнопка есть в EN и RU; клик создаёт ровно один новый гайд
на вкладке записи, после перезагрузки гайдов по-прежнему один; плашка-подсказка появляется в пульте; 0 ошибок в консоли.

Не проверено:
- Само автопереключение на вкладку: не работает в тесте, см. выше. Нужна ручная проверка на другом компьютере
  и, возможно, другое решение (например, открыть пульт после выбора вкладки или `window.focus()` из вкладки-цели).
- Попытка проверить через реальные клики мыши по рабочему столу: часть кликов попала не в окно тестового Chrome
  (на экране была другая программа). Больше так не делаю: проверять переключение нужно вручную.

## 2026-11-14: v0.3.0, запись в одно действие, демо про сам инструмент
Запись (`LiveCaptureWorkspace.tsx`):
- Зачем: при выборе вкладки в окне Chrome браузер сразу переходит на неё, и отдельный шаг
  «Откройте плавающий пульт» заставлял возвращаться во вкладку редактора.
- Теперь две карточки: «1. Начните запись» и «2. Снимайте каждый шаг». Кнопка «Начать запись» сначала открывает
  плавающий пульт (Document PiP, нужен клик), в пульте крупная кнопка «Выбрать вкладку для записи» вызывает
  `getDisplayMedia` из приложения (активация клика в окне PiP засчитывается приложению). Окно выбора вкладки
  Chrome показывает прямо внутри пульта, после выбора Chrome переходит в программу, пульт уже поверх.
  Пока запись не идёт, в карточке 1 написано, что делать дальше; если пульт закрыли во время записи, есть
  кнопка «Показать плавающий пульт». Без Document PiP (Firefox, Safari) кнопка сразу спрашивает вкладку и
  открывает пульт на странице, с пояснением.
- В пульте до начала записи скрыты «Снять кадр», «Снять весь кадр» и «Остановить запись». Убраны эмодзи 🏁 и 🔴.
  «Сменить окно / вкладку» теперь «Записать другую вкладку».
- Найден и исправлен баг: в плавающем пульте рамка шага съезжала по вертикали (на кадре 1440x900 примерно на
  12 процентов вниз). Причина: `instanceof HTMLVideoElement` ложно для элемента из окна PiP (другой `window`),
  и пересчёт с учётом полей видео не применялся. Заменено на проверку свойств `videoWidth` / `naturalWidth`.
- Отвергнуто: открыть пульт и окно выбора одним кликом (Chrome отклоняет `getDisplayMedia` с NotAllowedError).

Демо (`public/demo/how-to-guide.html`, `src/db/database.ts`, `App.tsx`):
- Зачем: гайд по Fabric не объяснял, как пользоваться инструментом.
- Новое демо: 18 шагов «How to make a step-by-step guide / Как сделать пошаговый гайд», EN и RU, красная рамка
  на нужном элементе и короткое «зачем»: новый гайд, начать запись, выбрать вкладку, окно Chrome, пульт поверх
  программы, обвести кнопку, рамка и курсор, размытие, подпись и голос, следующий шаг, завершить, список шагов,
  рамка в редакторе, подпись, «Размытие и другие инструменты», гайд для студентов, проект для редактирования,
  «Открыть гайд или проект».
- Скриншоты сняты скриптом с настоящего приложения в Chrome 157 при 1440x900 (`scripts/demo/`); программа для
  записи: учебная страница «Sales Portal». Шаги 3–11 склеены из двух настоящих снимков (вкладка + окно пульта
  540x680) с подписанной рамкой «Floating recorder (always on top)». Шаг 4: настоящее окно выбора вкладки Chrome,
  снятое с экрана и вставленное поверх пульта.
- Файл собран самим приложением кнопкой «Save project for editing» (4,2 МБ, с вложенными исходниками), поэтому
  он и открывается как гайд в любом браузере, и загружается в редактор без потерь.
- На главной новая кнопка «Как это работает: интерактивный гайд» (открывает файл в плеере в новой вкладке),
  «Попробовать демо» стала «Открыть демо в редакторе». `fabric-demo.html` удалён (есть в истории, тег v0.2.0).

Проверено (видимый Chrome 157 через Playwright, сборка `npm run build`):
- Запись: клик «Начать запись» открывает пульт, клик «Выбрать вкладку» в пульте даёт поток вкладки 1440x900,
  карточка показывает «Идёт запись», обводка кнопки в пульте создаёт шаг с верной рамкой (было y=24.5, стало 10.1
  при ожидаемых 10), три шага и переход в редактор. Окно выбора вкладки снято с экрана вручную (EN и RU Chrome).

- Демо: кнопка на главной открывает плеер, клик по красной рамке листает шаги 1→2→3→4, RU переключается,
