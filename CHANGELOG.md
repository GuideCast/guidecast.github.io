## 2026-11-14: v0.3.2, Chrome переключается на вкладку, подсказка про размер пульта
Переключение на вкладку (`LiveCaptureWorkspace.tsx`): ЗАРАБОТАЛО в тесте.
- Причина, по которой в v0.3.0 и v0.3.1 переключения не было: окно выбора вкладки вызывалось из окна пульта, а когда
  пульт уже открыт, Chrome не переходит на выбранную вкладку. Замеры в Chrome 157 (заголовок окна браузера):
  только окно выбора из главного окна: вкладка сменилась; пульт открыт раньше выбора (оба порядка вызова):
  вкладка не сменилась; одновременный вызов окна выбора и пульта: окно выбора отменяется (NotAllowedError);
  окно выбора, а пульт после ответа: вкладка сменилась И пульт открылся.
- Теперь «Начать запись» (один клик) вызывает окно выбора из главного окна, а после «Поделиться» открывает пульт.
  Chrome хранит активность клика около 5 секунд (замер: через 7 секунд пульт уже не открывается). Поэтому: если
  активность ещё есть, вкладка переключается и пульт открывается сам; если преподаватель выбирал дольше,
  остаёмся на нашей вкладке (`no-focus-change`) и появляется сообщение «Нажмите Показать плавающий пульт, затем
  откройте вкладку с программой». Жёлтая подсказка в пульте осталась как запасная.
- `CaptureController.setFocusBehavior` вызывается сразу после ответа; ошибок нет.
- Исправлено: видео в пульте не подключалось, если пульт открывался после начала захвата (эффект зависит от окна).

Размер пульта:
- Окно пульта открывается 420x560 (не больше экрана); замер в Chrome: 421x560. Если окно браузера задано флагом
  `--window-size`, Chrome игнорирует запрошенный размер и делает пульт размером с окно (особенность тестовой среды).
- Внутри пульта спокойная подсказка с иконкой «Мелко? Потяните за край или угол окна, чтобы увеличить.»
  Её можно закрыть крестиком, выбор хранится в localStorage (`gct_pip_resize_hint_hidden`).

Проверено (видимый Chrome 157, окно выбора вкладки закрывает флаг `--auto-select-tab-capture-source-by-title`,
без кликов по рабочему столу): один клик даёт живой поток (1942x1592), открытый пульт 420x560, заголовок окна
браузера «Sales Portal», `focusResult` равен `focus-captured-surface`, подсказка про размер видна.

Не проверено:
- Настоящее окно выбора вкладки с ручным нажатием «Поделиться» и живой человек: активность клика, ветка «выбирал
  долго» проверена только отдельным тестом API (7 секунд, пульт не открывается), в самом приложении нет.
- Жёлтая подсказка может мелькнуть и при успешном переключении (в тестовом Chrome вкладка считается видимой),
  в обычном Chrome она скрывается, когда вкладка уходит в фон.
- Закрытие подсказки про размер и её сохранение между сессиями; Edge, Firefox, Safari.
